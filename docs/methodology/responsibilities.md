# Verantwortlichkeiten

| Aufgabe | Entwickler | ChatGPT |
| --- | --- | --- |
| Ziel, Priorisierung | Definiert und entscheidet | Hilft beim Präzisieren |
| Architektur | Verantwortet Entscheidung | Analysiert Alternativen, Risiken |
| Implementierung | Steuert und prüft | Unterstützt bei Entwurf und Code |
| Tests | Bewertet Ergebnisse | Schlägt Testfälle und Analysen vor |
| Veröffentlichung | Gibt Inhalt und Merge frei | Hilft bei Sicherheitsprüfung |
| Dokumentation | Verantwortet Richtigkeit | Erstellt und aktualisiert Entwürfe |

## Grenzen
- Keine ungeprüfte Übernahme von KI-Code.
- Keine unautorisierte Veröffentlichung privater Daten.
- Keine automatische Freigabe sensibler Infrastrukturänderungen.
- Keine Behauptung technischer Nachweise ohne Belege.
- Fehler, Unsicherheit und nicht erfolgreiche Ansätze werden offen benannt, soweit öffentlich vertretbar.

GitHub ist das **persistente Projektgedächtnis**; ChatGPT ist ein Assistenzwerkzeug. Der Mensch bleibt verantwortlich.
