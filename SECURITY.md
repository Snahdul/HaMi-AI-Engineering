# Sicherheit und öffentliche Inhalte

Dieses Repository enthält ausschließlich Inhalte, die für eine Veröffentlichung bestimmt sind.

**Nicht in Issues, Pull Requests, Commits oder Screenshots veröffentlichen:**
- Tokens, Kennwörter, private Schlüssel, Zertifikatsgeheimnisse
- Interne IP-Adressen, DNS-Namen, Netzpläne, Tunnelkonfigurationen
- Personenbezogene Daten, Kundendaten, private Chatverläufe
- Private Quelltexte und Inhalte Dritter ohne Freigabe
- Unbereinigte Logs mit möglicherweise sensiblen Parametern

Bei versehentlich veröffentlichten Geheimnissen müssen Zugänge unverzüglich widerrufen bzw. rotiert werden; das Löschen einer Datei aus dem neuesten Commit entfernt sie nicht zuverlässig aus der Git-Historie.

Sicherheitsprobleme nicht mit geheimen Details in öffentlichen Issues melden. Kontakt: https://millmann.biz
