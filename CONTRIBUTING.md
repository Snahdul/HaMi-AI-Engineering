# Beiträge und Review

Dieses Repository ist primär eine kuratierte öffentliche Projektreferenz.

1. Ziel und Akzeptanzkriterien in einem Issue festhalten.
2. Nur für die Öffentlichkeit geeignete Inhalte verwenden.
3. Änderung in einem separaten Branch mit Pull Request einreichen.
4. Tests, Prüfung und Risiken dokumentieren.
5. Veröffentlichung und Merge erst nach menschlicher Freigabe.

Der öffentliche Verlauf soll auch Korrekturen und begründete Ablehnungen nachvollziehbar machen. Code wird nicht allein deshalb akzeptiert, weil er von einer KI stammt.
