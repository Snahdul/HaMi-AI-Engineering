# Geplante Demo: Public Issue Dashboard (.NET)

**Status: Konzept – noch kein ausführbarer Code.**

Eine kleine .NET-Anwendung soll öffentliche GitHub Issues eines konfigurierbaren Repositories darstellen. Ziel ist eine technisch überschaubare Demonstration mit nachvollziehbarem öffentlichem Entwicklungsprozess.

## Minimalumfang
1. Öffentliche Issues laden.
2. Titel, Status und Link anzeigen.
3. API-Fehler und Rate Limits verständlich behandeln.
4. API-Client und UI testbar trennen.
5. Ohne private Zugangsdaten arbeiten.

## Abnahmekriterien
- Dokumentierter lokaler Start mit .NET-SDK
- Automatisierte Tests für Transformation und Fehlerfälle
- Keine Secrets oder privaten Daten im Repository
- Öffentliche Issues und Pull Requests belegen die Entwicklung

Die UI-Technologie wird vor der Implementierung entschieden.
